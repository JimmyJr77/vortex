## Exact mechanics, geometry and timing

Start still in comfortable bilateral standing with relaxed natural arms. Build smoothly over **0–10m**, retain the selected relaxed rhythm over **10–20m**, then slow gradually through **20–35m**. The intended running segment is20m within a full35m protected corridor. Use natural reciprocal arms and self-selected coordinated steps; no rolling/three-point/falling start, forced early upright posture, stride/cadence quota, maximal second half, fly threshold, reactive cue or timed speed test is added.

The runoff must actually fit the chosen demand before release. Prior easy success does not prove that the retained15m runoff fits4/10 today. If it does not, hold/reduce, explicitly reconfigure or defer. The35m marker is not a forced stopping deadline, and the route is not lengthened silently while claiming intent-only progression. Exit into the designated outside one-way return, turn/rejoin under the existing conduct rules and recover fully.

Both run contexts use the same **25s active/exit allowance**:5s build +5s rhythm +12s gradual runoff +3s exit, followed by a separate **40s return** and **90s minimum recovery**. These are planning envelopes, never required segment times or gait speed. Earlier safe completion leaves quiet time; longer instruction/action/return delays or removes later opportunities. There is no corrective run or catch-up attempt.

All three age bands use D ceilings of **two single attempts standard or one compressed**, with actual smaller cap1. Both L modes have zero running under this card. The independently eligible long-walk alternative has one standard-L follow-up or zero compressed-L follow-up after the counted E0 orientation. Reference counts are not permission to restore a more recent smaller dose.

The saved traffic model retains three separate35m corridors at2m planning width each, each with its own outside return and rear waiting line. No shared merge, cross-lane rejoin or crossing of the next-athlete feed.
