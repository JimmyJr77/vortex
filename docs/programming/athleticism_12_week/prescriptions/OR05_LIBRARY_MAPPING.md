## CHEST-PASS-TEACH: OR-05's explicit proposed identity

Use stationary bilateral standing with comfortable unlocked knees, organized ribs/pelvis, and one individually fitting ball held with both hands at chest level. No deliberate dip/squat, step, jump or rotational wind-up is prescribed. On the single already explained cue, project forward from the chest into the declared open contained lane, extending both arms comfortably while retaining foot contact and a balanced finish. The inspected landing area contains the ball's natural descent after forward projection; it is not a downward aiming instruction or slam target.

Use an inspected dead- or low-bounce implement appropriate to that release and actual surface/containment. A slam ball is not automatically an equivalent medicine ball: design, mass, diameter, texture, grip and release behavior must fit the athlete and task. There is no intended wall rebound, catch, slam, chase or immediate second throw. Unexpected uncontained bounce/roll stops the station until clearance is restored.

Before the first counted E1 instructional release with own-ball retrieval, establish comfortable actual ball handling/chest start and the actual floor pickup, carry and floor set-down from counted P2 or a direct equivalent, comfortable unloaded arm path, understood no-catch/no-chase/wait/retrieval conduct, and verified equipment/space. Rack-only handling does not establish floor retrieval. **No prior successful throw is required.** Observe the actual controlled bilateral release, foot contacts, torso and finish within that first counted E1 attempt; the full global all-clear/retrieval conduct sequence is also observed in E1. P2 has no release and cannot grant a throwing or full retrieval-conduct pass. Unloaded arm movement or attendance alone does not establish loaded handling or a successful release.

Root must prescribe the actual ball mass/diameter/type, start/arm contacts, target geometry/distance, intended effort, bounded attempts, recovery and full clock. No numerical load or dose is presented here as a source default. This new teaching record has no exact canonical/profile ID.

Root's planning reference is a **soft low-rebound medicine ball,0.5 kg and18 cm diameter**, with actual inspected values recorded before use. This is an authored reference, not an age-based prescription or measured inventory claim, and it may be too demanding for some athletes. If release is unavailable but handling/return are comfortable, select the eligible no-release task; if handling is unavailable, select independently comfortable unloaded orientation. The first actual releases occur in the **main teaching block on the known cue** and are counted, including unsuccessful qualification/invalid attempts. There is no wall or catch.

**Known cue:** one early explained permission signal maps to one predetermined throw. This observes following that task-specific release instruction; it is not automatically a reaction-speed test, choice task or reactive catch. Possible JUMP-T and REACT-T entries depend on their separately defined criteria and **actual observed throwing/cue behavior**, not the exercise name or attendance.

**Global all-clear:** after release, athletes stay in their assigned waiting/finish positions. Collection begins only once all throws have stopped, balls have settled and the coach confirms the whole retrieval area/route is clear. No throw occurs while anyone retrieves. Root specifies who picks up/carries, the return path, handoff/set-down, safe waiting positions and how premature release/entry is handled. This global group rule is authored operational context informed by source lane shutdown, not a claimed exact source method.

Count every actual release, including invalid/qualification attempts. With feet grounded there are zero intentional athlete flight/landing events; this does not remove ball-path, handling or retrieval exposure. Bounded attempts do not expand to satisfy a valid-throw quota.
