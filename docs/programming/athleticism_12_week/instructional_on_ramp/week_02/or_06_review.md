The first unloaded hinge must already be controlled, but a perfect loaded repetition need not preexist. |
| A recent smaller bodyweight dose had no explicit first-loaded count hold. | First-DB ceilings of one, two or three repetitions retain all 20 seconds of first-handling time and the same gates. A compressed three-rep ceiling stays at its two-rep reference. These options never borrow the familiar-DB ten-second handling route. |
| The smaller P1 rehearsal incorrectly listed 60 seconds of inter-set rest. | P1 has one brief set; inter-set rest is not applicable. Its actual transition to the distinct P2 action is at least 54 seconds, versus 50 seconds for default D. Strength rest remains separately prescribed. |
| Landing errors needed actionable instructions in the session itself. | Uncontrolled extra steps, asymmetry, collapse, rebound or lost balance end the affected attempt. Record actual contacts; use only an eligible grounded action in a remaining scheduled opportunity or defer. Do not add attempts to earn a pass. |
| First implement handling could overfill the shorter booking. | Standard first-DB reference is 3/4/4 reps for the three ages, with 20 seconds handling. Compressed uses two reps for every age. Eight paired slots fit the stated hip block before four separately timed supporting roles. |
