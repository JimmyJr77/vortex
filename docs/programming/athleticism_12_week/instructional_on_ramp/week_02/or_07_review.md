# OR-07 — written athletic design review

**PASS for the written athletic lesson.** The exercise librarian, instructional/numeric specialist and independent programming critic review different requirements. This document does not establish current canonical approval, actual facility execution, athlete competency or a complete separate tumbling prescription.

The [coach session](or_07.md) and [structured prescription](or_07.json) teach a walking exit in an early-announced direction after a controlled straight stop and two-second balanced pause. The athlete retains the actually controlled approach. A supported static stance and four small complementary strength roles follow; the hip set is deliberately unloaded if the most recent actual OR-06 set used dumbbells. Every task includes the three ages, four booking/D-L modes, set purpose, execution, recovery, criteria and prior/current/next exposure.

## Findings and resolution

| Review finding | Resolution |
|---|---|
| Inspected terminal stops and immediate cuts do not describe the complete paused first-exit lesson. | A complete teaching proposal uses the existing proposal schema with null live IDs and unapproved status. Terminal-stop alternatives retain their separate identities and earn no exit credit. |
| Requiring a prior perfect exit would prevent teaching the first exit. | Actual corresponding stop control, ordinary walking/turning, conduct and suitable space permit the first counted E1 instruction. Current P2 can establish a walking stop; it cannot establish a jogging stop. A first jogging stop uses its separate terminal-stop route. |
| A diagonal exit extends beyond the former straight lane. | One protected 6 × 15 m shared teaching area incorporates the two closed adjacent approach lanes. Separate outside returns, rear-entry holding banks, staging and the observation pad are explicitly located and conditional on actual fit. |
| Preparation and main work use different return systems. | P2 retains three independently segregated returns. All close after the last preparation return; the opening five-minute main setup transfers the group and configures the two main returns. Both approach marker sets are pre-positioned. |
| Stationary alternatives had zero return but were included in generic central-staging prose. | Position/standing E1 remains in an inspected personal preparation bay. Any transfer back occurs within opening setup; its 10-second action occupies its numbered 25-second slot. There is no central staging, return or concurrent main action. Coach1 must see the bay from the observation pad; an unsuitable arrangement means defer. |
| Three, two or one attempts do not all observe both directions equally. | Record the first direction before release. Three opportunities are first/opposite/first; two are first/opposite; one observes the first side only. Smaller actual-history ceilings omit later opportunities. Faults consume attempts; there is no repayment side or automatic bilateral competency. |
| A default D prescription could restore a recent smaller stance hold or hinge count. | Explicit 1/2/3-second stance ceilings and 1/2/3-repetition hip ceilings preserve actual smaller work. Stance support/depth stay fixed. The unloaded hinge is a named reduction after loaded OR-06 work, with no hidden load trial. |
| P1 listed inter-set rest despite being one brief rehearsal. | Inter-set rest is not applicable. Actual full supported P1-to-P2 gaps are 46–72 seconds; shorter alternatives leave more time. S1 retains its separate 60-second recovery rule. |
| Inherited session metadata and outline preparation differed from the new lesson. | Source and exports now identify Week 2, Day 2 and paused-exit instruction. The explicit OR-07 outline amendment preserves the full preparation base and 90+90-second targets, retains straight-stop P2 and locates the first exit in counted E1. |

The independent critic returned scoped written PASS after the metadata/amendment corrections and again for the bounded stationary-bay correction. Movement intelligence is integrated within the eight existing tenets; it is not an additional tenet or time block.
