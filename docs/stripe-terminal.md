# Stripe Terminal at the front desk

Vortex uses [Stripe's server-driven Terminal integration](https://docs.stripe.com/terminal/payments/collect-card-payment?terminal-sdk-platform=server-driven) with internet-connected smart readers, such as the WisePOS E and Stripe Reader S700/S710. Stripe moves card data from the reader to its servers. Vortex staff select the reader and see the payment status in the browser.

1. Create a Stripe Terminal location for each participating Vortex facility and register its reader at that location. In a sandbox, use a [simulated reader](https://docs.stripe.com/terminal/payments/connect-reader?reader-type=simulated&terminal-sdk-platform=server-driven) such as `simulated-wpe`.
2. Apply the normal backend deploy migrations. Set `STRIPE_TERMINAL_ENABLED=true` and set `STRIPE_TERMINAL_LOCATIONS` to a JSON object such as `{"42":"tml_ACTUAL_LOCATION_ID"}` on the backend. Each key is a Vortex facility ID; each value is a distinct Stripe location in the environment's Stripe account. The existing `STRIPE_ENABLED`, Stripe API key, and signed webhook settings must also be configured. Use a sandbox key and a separate test database when rehearsing.
3. Verify the existing signed `/api/stripe/webhook` endpoint receives `payment_intent.succeeded`, `payment_intent.payment_failed`, and `payment_intent.canceled`. The app also checks the PaymentIntent directly when staff view its status.
4. Sign in as a staff member with Billing Manage permission and an assigned facility. Open **Billing → Account Billing & Enrollments** and choose **Take in-person payment**, or open **Store → Checkout** and select **Stripe card reader**. In a sandbox, send the payment to the simulated reader, simulate a decline, retry the same payment, and simulate approval. Verify the balance or order refreshes and the receipt is recorded.

Billing collects the household's current collectible balance. If a monthly invoice already owns the balance, use its existing payment link. Store orders stay pending until Stripe confirms payment. To abandon a store sale, cancel the reader payment first, then cancel the pending order to return stock. Online store checkout and monthly billing remain available.
