# Current payroll operating assumptions

This is the short review list for the hire-to-payroll implementation. The detailed decisions and exceptions remain in [the implementation register](PAYROLL_ONBOARDING_IMPLEMENTATION.md). This list describes the implemented baseline, not proof that Vortex's live employer configuration has been verified.
