## Benefit and compensation classification contract — verified 2026-09-10

Authoritative requirements:

- Report reviewed qualified overtime under 2026 box 12 code TT; the amount is the qualified premium, not all overtime wages. Preserve the full reportable amount rather than applying an individual's deduction limit. Box 13 retirement participation and third-party sick-pay treatment require explicit determination. The 2026 form also adds codes TA/TP and box 14b for tipped occupations; unsupported applicable categories must remain unresolved. [IRS 2026 W-2/W-3 instructions](https://www.irs.gov/instructions/iw2w3), [IRS August 2026 overtime guidance](https://www.irs.gov/pub/taxpros/fs-2026-13.pdf).
- Code DD health-coverage reporting has plan-specific treatment and transition relief, including employers required to file fewer than 250 W-2s in the preceding calendar year. Current facility headcount cannot establish that condition. HSA contributions use separate treatment rather than automatically entering DD. [IRS health coverage reporting chart](https://www.irs.gov/affordable-care-act/form-w-2-reporting-of-employer-sponsored-health-coverage).

Implementation contract (design decisions, not additional agency rules):

1. Retain an annual employer reporting determination: payment year, reviewed prior-year W-2 filing count when relied on, reporting disposition, source reference, actor, timestamp and immutable revision. Never default to relief from this application's employee count.
2. Retain per-employee annual health-coverage classification with explicit REPORT, RELIEF_USED, NO_APPLICABLE_COVERAGE or UNRESOLVED disposition. REPORT requires verified annual reportable cost and calculation/source evidence. Other dispositions require supporting evidence; they are not synonyms for zero. Keep the retained determination revision and annual payroll source fingerprint with the review.
3. Keep catalog monthly prices and actual employee deductions visible as supporting evidence, but do not multiply current prices by twelve or sum deductions to invent reportable annual cost. Coverage changes, employer-paid coverage, former employees and amounts paid outside payroll require reconciliation.
4. Add explicit applicability review for retirement contributions/participation, dependent-care benefits, taxable fringe benefits, third-party sick pay, tips, equity/deferred compensation and other reportable amounts. Do not silently set unknown W-2 boxes or flags to zero/false. Where an applicable treatment is not implemented, retain an unresolved issue and prohibit form approval.
5. Bind classification revisions to the later form fingerprint without making existing annual-input review fingerprints depend recursively on form review. A revised reporting determination or employee classification must invalidate form approval; it need not rewrite the earlier retained input snapshot.
6. The eventual form mapping must combine Medicare withholding for box 6, read the employer's retained Maryland ID for box 15, and map qualified overtime to TT independently of DD and other classifications. It must retain identity revision IDs and exact cents. An input review alone cannot satisfy the classification gate.

Required verification for this contract: positive reportable costs; supported relief with reviewed evidence; missing determination; unsupported applicable benefits; same-value changed evidence; stale annual inputs; concurrent corrections; historical snapshots; former-employee coverage; isolation across facilities; no-cost inference from deductions; and approval blocked until every applicable classification has an implemented, current disposition.

### Retained approval PDF downloads

The backend can render supported 2026 encrypted W-2 approval snapshots into static six-page employee packets (B/C/2 and instructions) using the pinned IRS template. Authorized admins download a selected current or historical approval from annual preparation. The endpoint enforces facility/employee ownership, no-store responses, snapshot identity checks and an audit event. Full identifiers appear only in the explicit PDF download, not ordinary history. Rendering rejects unsupported box/code/flag values or unreadable text overflow. This is a retained approval copy, not proof of furnishing or agency acceptance. Immutable encrypted packet storage is now implemented per approval on first download, with checksum verification and identical subsequent downloads. Electronic delivery consent/access demonstration, notification and paper furnishing evidence remain to be implemented.

### Undeliverable follow-up automation

Returned paper packets now generate payroll alerts transactionally. The regular workforce automation refresh reconciles alert state from packet furnishing history, reopening unresolved dismissed alerts and closing them after a later mailing or handoff. Refreshes and event writes share the packet lock. The furnishing panel displays the action needed for a returned packet. This is internal follow-up automation; no external message is sent.

Replacement furnishing linkage is now implemented: admins can select a newer same-employee/year packet’s current mailing or handoff, verify the relationship and retain an immutable link to the original return. The link becomes stale if either event history changes; workforce refresh reopens the follow-up alert. This does not implement W-2c generation, form-correction classification or agency amendment.

### Durable availability-notice preparation

Publication now creates an encrypted notice job in the same transaction. Notice content includes the required subject, portal access/printing instructions and payroll contact, with a retained checksum. Missing email produces NEEDS_CONTACT; workforce refresh can append a ready revision after contact completion and backfill earlier publications. Existing ready notice content is not silently replaced. Preparation is idempotent and does not send messages. Dispatch must revalidate consent, recipient/contact and current job revision; delivery attempts, provider acceptance, retries, uncertain sends and bounce handling remain required.

W-2 availability dispatch now claims before external I/O, retains append-only acceptance/skip/uncertainty evidence, serializes against consent withdrawal, and blocks changed terms/contact or unreadable artifacts. Workforce automation dispatches when transactional SMTP is configured and raises actionable warnings otherwise. An interrupted result write leaves an uncertain claim and cannot cause an automatic second send. The admin publication panel exposes mail-service acceptance without representing inbox delivery or employee access. No provider bounce processing, ambiguous-attempt reconciliation or controlled retry path is implemented yet; paper furnishing remains available through the retained packet workflow.

Paper fallback integration: the latest exact-packet paper mailing or handoff after publication resolves availability-notice follow-up and prevents an unstarted electronic send. A return removes that resolution; an independently accepted electronic notice can still resolve the notice task while the returned-paper warning remains. Existing mail-attempt evidence is retained. Alert reconciliation uses the furnishing lock and rereads current paper/send evidence before saving. The admin publication panel displays the paper event and explains the remaining history. Replacement-packet links are not yet used to resolve the original publication notice task.

A subsequent target return invalidates fallback on read and automation reopens any unresolved original notice warning. The UI retains the packet, link and event identifiers for inspection.
