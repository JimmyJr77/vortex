# Saved future direction

This roadmap is intentionally deferred until the single-workout exercise-library
milestone is complete.

## Production rollout

- Apply and rehearse migrations in staging, including backup and rollback.
- Run representative coach pilots and enforce keep/edit/swap/safety targets.
- Add tenant-isolation, role-boundary, concurrency, and load tests.
- Add operational dashboards for generation failures, shallow pools, fatigue
  failures, swaps, dose edits, AI cost, review queues, and media health.
- Schedule recurring exact-match media verification.

## Product evolution

- Longitudinal 7-, 14-, and 28-day workload awareness.
- Athlete-specific readiness and recovery state.
- Live capture of actual sets, reps, load, RPE, substitutions, pain, and
  technique events.
- Multi-week block planning, progressive overload, deloads, and event dates.
- Calibration analytics including reviewer variance, missing anchors, outliers,
  score distributions, and bulk recalibration.
- Release-to-release regression evaluation against historical coach requests.

## Current priority

The active priority is narrower: fully produce one accurate, scalable workout
from a canonical exercise library in which every existing card satisfies the
defined identity, taxonomy, anatomy, loading, fatigue, delivery-profile, media,
review, calibration, and automated-test requirements.
