The renderer verifies this digest and embeds a subset in each generated PDF. Runtime rendering needs no external font service. The original IRS template remains unchanged.

This face covers extended Latin, Greek and Cyrillic. It does not cover every writing system. Missing glyphs are rejected before review/signature rather than silently substituted. CJK and complex-script rendering require additional fonts and layout verification. Replacing or extending these assets requires canonical-field, rendered-text and visual checks.
