# Class 2 stimulus and choice review

The demand is accurate low-amplitude foot return, then organized force from split or single-leg support. E1 supplies the repeatability marker. Split-stance spring, supported upward projection, unilateral push, forward hip-driven release and unloaded-by-bodyweight ankle acceleration fill different supporting jobs. Light toe-lift and knee-control work precede the unchanged six strength roles.

Primary result: Keep ankle return centred while the support position changes slightly, preserving leg-force reserve for repeated stance.

Anchor/marker: E1 — Count accurate fore-aft line-hop landings within each six-contact set: return to the two declared positions without progressive drift, excess knee bend or rhythm loss. One crossing is one hop; six hops, not six out-and-back pairs. Compare the two sets only, not with Class 1 stationary pogo scores.

Prior records: Class 1 prescribed 39 landings/64 foot contacts and 9 primary set rounds, with actual work unknown. The new user instruction favors distinct drills, so its planned repeated E1 is replaced by a target-control task; the split squat, RDL and calf prescriptions remain unchanged. Actual response remains unknown.

Choice comparison and novelty: Six default explosive drills differ from Class 1 defaults. The forward toss appeared only as a Class 1 contingency, so it is not new if an athlete actually used that option; actual usage is unknown. Line target crossing changes displacement control, split pogo changes ankle-force stance, box landing changes receiving height, single-leg-to-two-foot jump changes takeoff/landing laterality, and fast seated plantarflexion removes bodyweight impact. Strength repetitions preserve useful comparison conditions.

Dosage/audit decisions: Reduced planned landings from 39 to 31 while adding placement/stance changes; did not raise strength volume. Rejected a longer hurdle circuit because precise low contacts are the objective. Specified box step-down accounting and a nonthrowing replacement so neither hidden landings nor unconfirmed throwing space enter the dose. E6 is explicitly rapid force practice, not a conditioning calf set.

Conditional progression: Treat the new tasks as conditional applications of existing skills, not earned difficulty. Keep actual prior loads only if recorded and appropriate today; otherwise select through preparation. Class 3 may emphasize unilateral stance force, but with absent feedback keep impact modest and change no automatic load/rep variable.
