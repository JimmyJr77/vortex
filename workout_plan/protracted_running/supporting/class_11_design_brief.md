# Class 11 stimulus and choice review

The emphasis is force expression with supported feet and a quiet pelvis, preserving training quality without an impact requirement. E1 anchors quick knee-flexed ankle force. Long-lever hip drive, split-base held-implement drive, resisted hip extension, dorsiflexion and hip abduction cover the distinct support/recovery actions. Every rapid task is brief and light; familiar light foot/adductor control precedes six challenging strength roles.

Primary result: Maintain rapid stance-support force with no planned jump landings, preparing for a controlled final comparison exposure.

Anchor/marker: E1 — For each leg, compare the two sets of three heel rises: similar heel height, steady small knee bend, no ankle roll and a visibly crisp rise. Forefoot stays grounded. This is execution consistency, not measured power, tendon stiffness or clearance for more impact.

Prior records: Class 10 prescribed 24 landings including twelve unilateral events and six primary rounds. No actual response is known. Class 11 uses zero planned flight and retains six primary rounds as a deliberate support option; this is not a claim the athlete needs a taper or is sore. Any actual competition schedule still governs placement. Actual response remains unknown.

Choice comparison and novelty: Default rapid tasks introduce standing single-leg knee-flexed ankle force, a longer-knee hip-drive lever, retained split-base implement acceleration, isolated resisted hip extension, resisted dorsiflexion and grounded lateral hip acceleration. The held-ball task was previously a contingency and may not be novel if actually used; that history is unknown. Several are declared force/support variants rather than new families. Familiar light control work intentionally recurs under the user's allowance for strength continuity.

Dosage/audit decisions: Kept all six rapid slots meaningful while removing planned flight; did not relabel a steady hold or slow strengthening rep as explosive. Rejected added jump novelty before the final comparison. Each band-dependent task has a lower-resistance same-action option, and that lower load is not equated with the default. Primary work remains challenging despite the small one-round allocation; the class is not assumed to be a medically indicated deload or a competition taper.

Conditional progression: No exercise/load progression is earned without actual response. Use this support-focused prescription when current readiness and schedule suit it; it does not guarantee recovery. Class 12 should return the original ankle marker and selected strength anchors under matching conditions, with deliberate repeat exceptions documented rather than inventing a new test.
