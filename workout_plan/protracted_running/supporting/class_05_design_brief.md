# Class 5 stimulus and choice review

The target is force from the hip behind the stance leg and active lower-leg recovery. E1 anchors a paused forward push. Split and single-leg takeoffs change leg contribution while preserving two-foot receiving. Offset swing and hinge-dominant release express hip force against light implements; rapid knee flexion addresses leg recovery. The primary hinge and knee-flexor strength roles receive priority while calf work is reduced.

Primary result: Create hip-driven forward force and controlled hamstring contribution without adding a large ankle-rebound dose.

Anchor/marker: E1 — In each two-attempt set, record a true two-second pause before the forward push and a stable two-foot landing held for two seconds. Record re-dips and balance steps. Keep the modest distance/start depth comparable within the task; do not compare it with a countermovement or vertical jump.

Prior records: Class 4 prescribed 23 bilateral landings and nine primary rounds with concentrated ankle work. Actual completion/recovery remain unknown. Class 5 uses only twelve planned landings, reduces bent-knee calf work to one set and temporarily omits the separate straight-knee calf role in favor of a supported hip-extension finish. Actual response remains unknown.

Choice comparison and novelty: The six default drills introduce a paused forward vector, split-to-parallel forward finish, single-leg forward push with shared receiving, offset bell loading, a hinge-only release and isolated rapid knee flexion. Several are declared relatives of prior vertical jumps/scoops/swings; their joint action, vector or force-sharing jobs change meaningfully. They are not counted as unrelated exercise families. The box-style seated takeoff was not repeated merely to fill an explosive slot.

Dosage/audit decisions: Reduced landings and calf sets while increasing hip/hamstring emphasis; retained only one hip-thrust and one walkout working set to limit overlapping posterior-chain fatigue. Limited rapid curls to four per leg and specified an unresisted replacement for unconfirmed anchor hardware. Rejected Nordic-drop/catch variations because the unknown cohort response does not justify that eccentric demand.

Conditional progression: Retain the RDL and split-squat prescriptions unless actual execution/effort warrants a load adjustment; no automatic increase. New swing/throw/curl conditions require demonstrated control at their small doses. Class 6 should consolidate pelvic control with modest lateral demands, not assume these hip-focused tasks were performed.
