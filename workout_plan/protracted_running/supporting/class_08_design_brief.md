# Class 8 stimulus and choice review

After the prescribed linked-contact emphasis, this class restores isolated receiving. E1 anchors the coordinated countermovement forward push. Raised receiving, nominated single-leg receiving, low obstacle clearance, a stationary split-stance exchange and a grounded preload-to-rebound task expose different foot-placement demands. Primary step-up strength supports raising body mass through the stance leg; the remainder retains ankle, hinge and leg-recovery roles.

Primary result: Produce a short forward push and receive it under a controlled stance position without an external drop or run-up.

Anchor/marker: E1 — Count controlled finishes within each two-attempt set: one dip and coordinated arms, two-foot landing beneath the body held for 2 s without an extra step. Keep the modest chosen distance repeatable; farther is not automatically better for this support task.

Prior records: Class 7 prescribed 29 landings, twelve single-leg receiving events and linked alternatives, but no actual completion is known. Class 8 restores full resets and uses only four single-leg receiving events. The new main step-up uses the same 2 × 6 per-leg working count as the earlier split-squat anchor; the task change is conditional, not an automatic load progression. Actual response remains unknown.

Choice comparison and novelty: The default drills add integrated countermovement forward push, raised shared receiving after one-leg propulsion, two-to-one forward receiving, isolated hurdle clearance, a single split-stance exchange and grounded preload-to-rebound. They are meaningful variants of earlier jump families with changed force-sharing, clearance or coupling, not arbitrary new labels. Returning simpler floor/no-switch mechanics as readiness replacements is intentional.

Dosage/audit decisions: Reduced unilateral receiving to four events after Class 7's linked emphasis and rejected any external box drop. A possible repeated split-switch sequence was reduced to isolated single switches with full rest. The grounded snap-down is separated from its one actual landing in the workload count. New main step-up is conditional on box fit and leg-dominant execution; no load or depth is presumed earned.

Conditional progression: Use current technical control to select each receiving route. Keep a consistent step height/stance and record the load if performed; no future percentage increase is scheduled. Class 9 can emphasize rapid force against light external resistance while reducing landing exposure, provided the implement can be handled securely.
