## Substantive audit decisions and corrections

**Variety was applied to mechanical tasks.** A fore-aft pogo target, split-base pogo, low-box receiving, same-leg versus two-foot receiving, isolated versus linked contacts, static versus countermovement initiation and guided versus freely swinging resistance do not all solve the same constraint. They are still related families. The register explicitly avoids implying that a new name, rep count or load produces a new movement family. Class 12's three repeated defaults are marked: original pogo comparison, familiar split-base toss, familiar two-hand swing. Earlier optional substitutions may further reduce actual novelty; that cannot be determined without feedback.

**Impact was not made to rise every class.** Default landing events are 39, 31, 16, 23, 12, 26, 29, 21, 4, 24, 0 and 28. The types matter more than that list: linked contacts in Class 7 can be more demanding than isolated ones at similar counts, loaded Class 9 landings are distinct, and raised-box receiving is not mechanically equivalent to floor receiving. Those tasks have current-readiness conditions and fully dosed simpler replacements. No externally imposed depth drop was added.

**Primary strength remained productive after explosive work.** Working rounds are 9, 9, 8, 9, 8, 7, 7, 7, 7, 6, 6 and 6. Higher-priority lifts retain more investment early; later one-round support prescriptions still need challenging load/leverage and technical reserve. Class 12 deliberately does not restore the original nine-round volume simply because it is the final number. Strength reallocation is explained, and the previous/current dose of every recurring anchor is traceable.

**Overlapping tissues were treated explicitly.** Knee-flexed and straight-knee calf work have different positions but overlapping tissue demand. Class 4 limits its additional fast calf work and removes unilateral receiving; Class 5 reduces calf work while prioritizing hips/hamstrings. RDL, walkout, supported hip extension and fast hip drive differ in joint action, support or intent but still share tissues. Their supporting doses remain small. S work never has a burnout target.

**Identity ambiguity was corrected.** The original ambiguous forward-hop library key describes a bilateral jump; the same-leg forward hop remains an explicit proposed addition with no misassigned identifier. The generated box-jump source confirms ordinary bilateral Box Jump mechanics; step-down/reset is required execution, not an independent novel drill family. Unverified exact variations throughout the later classes are clearly marked in the complete register.

**Presentation and arithmetic were reconciled.** Aggregate counts now mean total across both sides, so an eight-swing total is not labeled eight per stance. Human-readable working/preparation units replace raw dictionary notation. Sequence lengths and paired landing counts are explicit. The current ledger/state covers all twelve classes; the original one-class checkpoint is retained only as labeled historical evidence. Every current class file is checked against its saved prescription record or, for Class 1, the original authoritative table/ledger.

## Progression and comparison limits

An instructional progression is not an earned athlete progression. Every later class is conditional on current ability and recovery. New tasks may be replaced with the stated simpler version; that change must be recorded rather than treating the default as performed. Without feedback there is no known individual response, no achieved strength gain and no cumulative athlete load to report.

Class 12 E1 deliberately preserves the original first-position pogo dose, hand position, low-height intent and rest. A comparison is possible only if actual compatible earlier observations exist. Other jump variants are not substituted for that measurement. The final strength block has fewer sets and different preceding tasks than Class 1; even matching first-set observations have contextual limits. If no earlier data exists, the final class establishes a new baseline.

## Remaining direct-practice and delivery facts

This is a gym support curriculum. It does not provide aerobic running exposure, sustained-pace practice or pace-selection decisions and cannot establish running-economy improvement from gym observations alone. No additional running block is silently added.

Existing preparation content/time, athlete history and symptoms, actual recent/upcoming training, group size, staff, booking, appropriate implement loads, safe band attachment, support dimensions and lane width remain unknown. These are visible conditions for delivery, not fabricated completed checks. The written curriculum is complete under those stated assumptions; specific athlete implementation requires the actual facts.
