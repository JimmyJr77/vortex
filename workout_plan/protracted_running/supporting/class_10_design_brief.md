# Class 10 stimulus and choice review

The target is consistency of the initial push and receiving position, not fatigue tolerance. E1 provides repeated isolated ankle-hop observations on each leg. Small split-stance travel, shared diagonal receiving and a low raised same-leg finish vary placement/support. Dead-stop hip drive removes swing carryover; single-leg bridge drive supplies rapid terminal hip force without a landing. Familiar foot control and a small pelvic-control task precede six meaningful single-round strength roles.

Primary result: Repeat accurate foot return and stance force with full resets, using a smaller primary-strength allocation for consolidation.

Anchor/marker: E1 — For each leg, record clean centred landings in the two sets of two isolated ankle hops. Start each attempt tall and still, keep knee motion small and land over the foot for 2 s. Compare only matching same-leg full-reset attempts; do not compare them with continuous pogo contact rhythm.

Prior records: Class 9 prescribed four loaded landings plus thirty nonflight force efforts and seven primary rounds. Actual response remains unknown. Class 10 uses unloaded isolated contacts, twelve single-leg events in total, and six primary rounds. The step-up returns at one set per leg rather than the earlier two; this is deliberate consolidation, not a response to assumed fatigue. Actual response remains unknown.

Choice comparison and novelty: The six default executions add isolated ankle initiation, split-base forward translation, shared diagonal receiving, whole-leg same-foot raised receiving, dead-stop implement initiation and unilateral rapid hip finish. These are purposeful support/coupling variants of established families. The seated short-foot task is an intentional familiar control exercise; no new foot exercise is invented just for a different name. Known simpler replacements are not counted as novelty.

Dosage/audit decisions: Kept impact to 24 events and changed primary allocation to six meaningful challenging rounds. Distinguished ankle-only E1 from whole-leg E4 so the raised/floor replacement cannot become a duplicate slot. Dead-stop swings specify one actual swing per hike/park. No extra load or contact target is used to make a consolidation class artificially harder.

Conditional progression: Hold load/height/range unless actual control and recovery justify a specific change. The goal is repeatable execution under matched conditions, not a higher total. Class 11 should retain controlled force reserve with low-impact support options and adjust to the actual sport schedule if it becomes known.
