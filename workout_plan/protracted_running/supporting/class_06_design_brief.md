# Class 6 stimulus and choice review

This consolidation exposure addresses unwanted side-to-side pelvic motion in stance, not sport cutting. E1 supplies a small lateral rhythm marker; E2/E3 use limited single-leg acceptance in diagonal and lateral vectors. Raised two-foot receiving, split-stance forward release and a grounded lateral step-up express force with different support conditions. Light arch and trunk work set up targeted hip/adductor strength.

Primary result: Keep the pelvis supported over the foot during small frontal and diagonal force demands.

Anchor/marker: E1 — Count centred contacts in each six-hop lateral set while pelvis and feet face forward, without crossing feet or increasing travel. Keep the same small gap. Lateral-hop rhythm cannot be compared numerically with fore-aft or stationary pogo performance.

Prior records: Class 5 prescribed twelve bilateral landings and eight primary rounds emphasizing hips/hamstrings. No actual response is known. Class 6 reintroduces ten single-leg receiving events, matching the written Class 3 count rather than increasing that exposure; primary volume falls to seven rounds while frontal strength roles replace some posterior-chain work. Actual response remains unknown.

Choice comparison and novelty: Six explosive executions differ from prior defaults through lateral rhythm, a diagonal same-leg vector, opposite-leg transfer, raised lateral receiving, split-stance forward release and grounded lateral elevation. The box/step-up/toss choices are related variants with explicit vector/support jobs. The supported single-leg short-foot task deliberately revisits arch control under a changed support condition; it is not claimed as a new exercise family.

Dosage/audit decisions: Held unilateral receiving to the earlier written ten-event dose and avoided long/skater-continuous bounds in this consolidation class. Reduced primary rounds to seven while replacing hip-thrust/walkout/hip-flexion emphasis with lateral and adductor roles. P6 remains challenging short-lever strength, while S2 is deliberately easy. Checked that step-downs, held seconds and replacement throws are counted separately.

Conditional progression: Do not interpret the middle class as proof of adaptation. Use the same recorded split-squat and supported-hinge conditions only when actual data exists; otherwise calibrate anew. The next class may introduce very short linked contacts only with demonstrated current control; no linked sequence is earned by writing Classes 1–6.
