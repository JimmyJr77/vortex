# Class 7 — design audit

**Previous exposure review:** Class 6 prescribed twelve locomotor attempts and six travel reversals, with only two bilateral flight landings. No actual control or recovery data is available.

**Observed response:** None reported. The prior class and new class are prescriptions, not actual exposure.

**Selection and revision:** Counted curved heading change separately from planted direction changes. Limited the rotational bound to two total landings and replaced the extra adductor-light set with easy ankle eversion so Copenhagen work is not preceded by redundant adductor loading.

**Progression/workload decision:** Use a new exit angle and entry shapes with controlled speed; reduce true running cuts to four rather than increasing speed and cut count together. Keep rotational flight very small and conditional on alignment. Return to the reduced familiar Class 5 strength pattern: one round each, target reserve unchanged. No load increase is assumed from the written Class 6.
