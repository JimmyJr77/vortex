# Class 11 — design audit

**Previous exposure review:** Class 10 prescribed fourteen discrete cuts, four unilateral landings and nine primary bouts. No actual fatigue or performance data was supplied.

**Observed response:** None reported. The prior class and new class are prescriptions, not actual exposure.

**Selection and revision:** Rejected another lateral rebound-return pair because Class 2 already used it. Used a bilateral-to-unilateral landing instead. The V route has exactly two changes, and rebound work is two flights only; no extra finishing block.

**Progression/workload decision:** Reduce discrete cuts to eight and keep each flight small. The new false-step and mixed-corner tasks apply prior qualities but do not provide a matched test of previous drills. Keep one round per lift, familiar technical reserve and no automatic load increase. Use stable goblet squat and the already introduced hip thrust; omit the separate long-lever bridge this day to avoid unnecessary posterior-chain overlap.
