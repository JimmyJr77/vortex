# Class 2 — design audit

**Previous exposure review:** Class 1 prescribed 18 locomotor attempts, four unilateral landings and 13 primary bouts; actual response is unknown. Its six drill identities were reserved against reuse.

**Observed response:** None reported. The prior class and new class are prescriptions, not actual exposure.

**Selection and revision:** Reduced the main shuffle entry to 1 m so stopping and the 90-degree exit can be planned in a compact bay. Kept only one rebound pair each way and one lateral-lunge round. Grounded ball work replaces another jump exposure; no throwing wall is assumed.

**Progression/workload decision:** New lateral transitions replace the earlier reversals; they do not imply a faster entry was earned. Running attempts drop while modest bilateral elastic/landing work is introduced; these loads are tracked separately. Retain the same RIR and technique on lateral lunge, RDL, split squat, bridge, Copenhagen and soleus. Reduce split squat to one round per side because the new rebound work adds lateral acceptance. No load increase is prescribed without actual feedback.
