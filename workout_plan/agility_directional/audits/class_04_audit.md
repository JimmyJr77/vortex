# Class 4 — design audit

**Previous exposure review:** Class 3 prescribes eight locomotor attempts, six direction changes, four bilateral/four unilateral landings and eleven primary bouts after retaining the one-round split squat. Actual response is unknown.

**Observed response:** None reported. The prior class and new class are prescriptions, not actual exposure.

**Selection and revision:** Removed another closeout-style linear stop because it would largely duplicate Class 1. Used a gait transition instead. Kept the complete stop-restart path inside 10 m and reduced strength rounds while preserving six useful lifts.

**Progression/workload decision:** Consolidate the common stop-and-drive quality through different tasks, with only two direction changes. Small line hops are tracked separately from unilateral landings. This is not automatic overload. Hold split squat at one round, and reduce RDL and soleus to one round each. Retain the same execution and 2–3 RIR targets; do not raise loads to compensate for fewer sets.
