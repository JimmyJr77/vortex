# Lower Body Force Generation — 12-week plan

One coached class per week for twelve weeks, for ages 12–14 with established basic lifting and landing technique and qualified supervision. Focus: knee, hip and ankle force for upward and short forward projection. The program sits in the **Athleticism Accelerator → individual 12-class programs** collection as **Lower Body Force Generation**.

Each week uses the existing **Access & Prepare 1**, followed by **6 explosive tasks, 2 light stabilization/resilience exercises and 6 challenging primary-strength exercises**. Preparation is referenced unchanged. The exact seven-category framework is preserved in [curriculum.md](curriculum.md); this program maps primarily to **Jumps > Vertical / Horizontal**, with limited **Sprinting > Acceleration (straight-line and multidirectional)** practice. It does not add an eighth category.
