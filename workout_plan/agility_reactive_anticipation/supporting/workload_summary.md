## Contact types and conventions

A landing event is one flight ending; a bilateral event loads both feet. A split landing is counted as bilateral but has asymmetric loading. Locomotor foot contacts, connecting steps, stopping steps and walk-downs are not assumed to equal jump contacts. Class 11’s four gallop first-foot landings have four subsequent trailing-foot contacts, recorded separately. Class 9 also has four medicine-ball receptions; those are not athlete landings. Class 12 has six grounded swings, not six throws or jumps.

## Dose changes and substitutions

Class 1’s mirror task allows up to 18 m cued movement plus 6 m terminal stopping; its complete locomotor budget is up to 56 m including all stated stopping allowances. Detailed distance accounting for Classes 2–12 is in each class data file and ledger. Fields distinguish acceleration, controlled movement, float distance and stopping; do not add alternative versions together. Jump/bound distance is individualized and additional to running distance.

The full-route values are planning ceilings under the stated execution. Compact same-drill options in angled classes retain the same attempts/landings but reduce route distances; their exact replacements and resulting metres are written in each class. False starts and extra recovery steps belong in actual logs, even when they exceed expected planned travel.

For every Class 2–12 Copenhagen replacement: remove 30 primary hold-seconds and add 16 dynamic adduction reps; remove 10 preparation hold-seconds and add eight preparation reps. Primary rounds/bouts stay unchanged. The Class 1 replacement follows the same numerical conversion. Seated band curl instead of prone manual curl retains sets/reps/sides; split squat instead of step-up also retains them and does not duplicate another primary slot in those classes. Floor bridge instead of hip thrust retains reps but changes range. Log variants separately.

Short-foot, step-down, ankle eversion, Pallof, easy heel-dig and light lateral walk doses remain individually stated in each class. Dynamic counts for lateral walks count each resisted step. Holds are listed separately from dynamic actions, including holds within a dynamic Pallof press. None is an extra finisher.

Primary set rounds are not side-specific bouts: 2 × 5/leg = two rounds, four bouts, twenty reps. Each lift includes explicit easy preparation; extra ramp sets must be logged. Rest between sides, rounds and exercises is included in timing estimates. Instruction/queue time may serve recovery only if actual athlete flow supplies the required interval; never double-count it or shorten recovery to fit a booking.
