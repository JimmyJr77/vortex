# Vortex Athletics — 12-Class Focus Curriculum Specification

## Purpose

Develop a progressive, coach-usable **12-class curriculum for one requested performance focus area at a time**. Devote each iteration to the best defensible next class, not to filling twelve templates. Every exercise must have a specific role in the day's primary effort.

This is a workout-programming task, not a request to build software, redesign the exercise taxonomy, or create a weekly calendar. Use the exact framework and class structure below. Body control/tumbling is programmed separately.

"Best" means purposeful, appropriately demanding, feasible, and revisable against evidence and athlete response. Do not claim a workout is scientifically perfect or guarantee outcomes.

---

## 1. Exact performance framework

Preserve these **seven categories and their subcategories**. Do not add, merge, rename, or reorganize them without explicit instruction.

### Protracted running
- Endurance
- sustained pace
- pacing control

### Sprinting
- Acceleration (straight-line and multidirectional)
- Maximum velocity

### Jumps
- Vertical
- Horizontal
- Lateral
- Force absorption
- Elastic rebound

### Agility
- Deceleration
- Change of direction/reacceleration
- Reactive agility and anticipation

### Object control & receiving
- Tracking
- Catching/receiving
- Controlling/manipulating objects

### Upper-body force generation
- Pushing
- Pulling
- Straight-line projection (such as chest passes)

### Rotational explosiveness
- Upper-body emphasis (rotational throws, punches, and swings)
- Lower-body emphasis (rotational kicks)

Strength, stability, explosiveness, and resilience support the selected focus; they are not additional performance categories. Body control remains separate.

## 2. Curriculum scope and run behavior

A **focus area** is the requested training target within this framework. For example, "Vertical Jumps" maps to `Jumps > Vertical`. "Acceleration" maps to the complete listed subcategory, with straight-line and multidirectional applications available within that curriculum. A category-wide curriculum is appropriate only when requested.

- Each requested focus receives its own twelve-class progression. Do not treat twelve classes spread across all seven categories as twelve classes for each focus.
- Work on the requested focus only; do not generate every curriculum automatically.
- A class is an instructional/training exposure, not necessarily a consecutive day or one calendar week. "12-day workout for Vertical Jumps" means twelve numbered classes unless a calendar is explicitly requested.
- **Default run boundary: finalize one new class per run.** Review saved work, develop the next class, audit and revise it, save it and its handoff, then stop. The next run resumes from that state.
- If explicitly instructed to complete several classes in one execution, still finish, audit, and save each class before developing the next. Do not bulk-fill later classes or reduce their detail.
- Default target when this specification is invoked without another named focus: **Vertical Jumps**. Start at Class 1 only when no valid curriculum progress exists.

## 3. Fixed class architecture

Every class must use the following order and exact exercise counts.

| Section | Requirement | Intent |
|---|---|---|
| **1. Access & Prepare 1** | Reference the existing predetermined sequence. Do not create or modify it. | Existing preparation, supplied separately. |
| **2. Explosiveness** | **Exactly 6 exercises.** | Explosive practice supporting the day's primary effort. |
| **3. Strength (Stabilization/Resilience)** | **Exactly 2 exercises.** | Light-load, stabilization/resilience-focused strengthening supporting that effort. |
| **4. Strength (Primary)** | **Exactly 6 exercises.** | Challenging strength work most directly supporting that effort. |

There are **14 prescribed exercise entries outside the existing preparation sequence**. Do not add finishers, conditioning circuits, extra reaction blocks, accessory lists, or tumbling exercises. Non-exercise notes, assessment criteria, timing, and programming rationale may follow the four sections.

### Counting rules

- An exercise performed on both sides is one exercise entry; prescribe and account for work on both sides.
- Multiple sets of one exercise still count as one exercise.
- Load-preparation sets for an already listed strength exercise do not create another exercise slot. Identify them separately from working sets.
- An alternative or regression is a **replacement**, not additional work. State "use instead of," not "also perform."
- Do not conceal several exercises in one row under "circuit," "combo," or "series."
- Do not fill separate slots with the same exercise at slightly different loads or renamed duplicates.
- Related variants may occupy separate slots only when they have genuinely distinct jobs. For example, a paused jump and a countermovement jump can address different takeoff tasks.
- Do not count one performance of an exercise toward two sections. Avoid identical exercise prescriptions across sections merely to meet the count.
- Every prescribed slot must contain real, purposeful work. Zero-dose entries are not a way to satisfy the count.

## 4. Athlete and planning assumptions

### Baseline

Use **ages 12–14 with established basic lifting and landing technique** as the foundational prescription. Training history, readiness, technical competence, and available supervision determine suitability and loading; age alone does not.

Class 1 is the beginning of this curriculum, not necessarily the athlete's first training session. Do not automatically turn it into a beginner-only introduction or restart competent returning athletes at an unnecessarily basic level.

Keep the main output focused on this baseline. Include an exercise-specific regression or progression when needed for execution, but do not expand every class into multiple age-group programs unless requested.

### Known and unknown information

Read relevant repository instructions, current curriculum files, equipment information, exercise records, and athlete feedback when available. Use the user's current specification for this curriculum rather than silently importing an incompatible older session template. Flag unresolved conflicts with other governing requirements.

Do not claim an exercise, machine, lane length, class duration, staffing level, or athlete test result is available or confirmed unless the supplied context establishes it. Record practical assumptions. For equipment uncertainty, identify a suitable replacement rather than adding another exercise to the session.

Do not invent a duration for Access & Prepare 1. If its duration is unavailable, report the estimated time for the prescribed work separately and leave the complete session duration unresolved.

### Confirmed viable equipment and training space

The owner has confirmed the following resources are available for curriculum programming:

- Rubber plates
- Dumbbells
- Kettlebells

- Wall balls
- Slam balls
- Medicine balls
- Landmines (1 handed, 2 handed)
- Cones
- Small hurdles
- Agility ladders

- Boxes (for box jumps)
- Bands (light and heavy)
- Jump ropes
- Timing gates

**Programming constraints:** Use this inventory when selecting exercises and planning stations. Bodyweight exercises remain available. Treat unlisted equipment as unconfirmed, not automatically available. Apart from the three lanes and their 10 m length, equipment quantities, load ranges, dimensions, and device capabilities have not been specified; do not invent them.

The three 10 m lanes are not a confirmed continuous 30 m runway. Account for required run-up, stopping space, and throwing clearance without assuming extra space exists. Timing gates and force plates may support assessments within the listed exercises, using only capabilities verified for the available setup; do not add extra exercise slots to use them.

### Loading and execution

- Primary strength means challenging, technically controlled strengthening, not light balance work or a breathless conditioning circuit.
- Do not interpret "intense" as maximal testing, forced repetitions, technical failure, or maximal loading on all six exercises.
- Prescribe load selection through demonstrated ability and a clear effort target. The supplied example uses approximately **2–3 technically sound repetitions in reserve**, rather than a universal weight for every athlete.
- Stabilization/resilience exercises remain light and controlled. They should not become pre-fatigue tests that undermine primary lifting.
- Give each exercise suitable recovery, execution cues, and hold/regress/stop criteria. Use qualified supervision for the target cohort.
- Preparation sets for heavy working sets are allowed, but do not invent a replacement warm-up or an additional preparation exercise sequence.

## 5. Exercise-selection requirements

### One primary effort, complementary jobs

Before selecting exercises, write a short **daily stimulus brief**:

1. The specific performance result being trained today.
2. The key movement demand or limiting factor addressed.
3. The primary performance exercise or assessment anchor.
4. The distinct supporting jobs needed from the other exercises.
5. One observable quality marker and the day's important constraints.

Then choose exercises to fill those jobs. Do not choose fourteen favorite exercises first and invent generic benefits afterward.

### Explosiveness: six purposeful exercises

Identify a primary performance exercise where appropriate. Allocate volume according to importance; six exercises do not imply six equally large or equally demanding workouts.

Each exercise must involve an appropriate explosive intent or clearly relevant rapid force-expression task. Differentiate low-amplitude elastic work, maximal-height or distance efforts, approach efforts, unilateral work, and ballistic throws where relevant. Do not treat every repetition as equivalent loading.

Sequence the work so the key task can be performed with the required quality. Supporting drills must not exhaust the athlete before the primary objective. Prescribe full resets where appropriate and avoid turning maximum-intent work into conditioning through rushed recovery.

### Stabilization/resilience: two targeted exercises

Use light external resistance or suitable bodyweight strengthening to address relevant joint control, postural control, controlled force acceptance, or tissue-loading needs. Each must have a specific connection to the day's task.

These are strengthening exercises, not a generic mobility list. Do not default to an unrelated balance drill and abdominal drill on every day.

### Primary strength: six direct contributors

Choose the six exercises that most defensibly support the selected performance effort within the total workload. Assign each a specific strength role and justify overlap.

The first exercise(s) may receive the largest investment; supporting strength exercises may use fewer challenging sets. Six slots do not require equal volume or six maximal compound lifts.

Do not insert unrelated pushing, pulling, or other movements solely to create a generic full-body workout when the request is focus-specific. Do not confuse extra complexity, unstable surfaces, or fatigue with strength development.

### Exercise library and evidence

If an exercise library exists, use its canonical names and identifiers where available. Do not invent identifiers or claim an exercise exists in the library without checking. Label useful missing exercises as proposed additions rather than substituting an inferior choice merely because its name is convenient.

Distinguish the intended mechanical role of an exercise from a demonstrated performance outcome. Verify consequential claims with accessible primary research or official specialist guidance when tools permit. Keep a concise source/assumption record; never fabricate references or imply that sources validate the exact whole session.

## 6. Focus areas that need special care

Apply the same fixed structure to every requested focus without mislabeling exercises.

For example, sustained running is not an explosive exercise, and ordinary catching practice is not automatically strength training. For protracted running or object-control targets, this template may provide substantial **support training** without all the direct endurance or perceptual/skill practice needed for a complete performance program.

Build the strongest honest support session within the requested architecture. State any material direct-practice gap plainly. Do not quietly add a fifth training block, call steady running "explosiveness," claim general strength replaces catching skill, or claim the template fully develops a quality it does not directly train.

If the constraints cannot support a defensible session, explain the precise conflict and smallest proposed change. Do not silently change the exercise counts or pass an unresolved session as finalized.

## 7. Iterative development protocol

### A. Establish a small, provisional twelve-class map

On the first run, create a brief roadmap of **one or two lines per class**: intended emphasis, continuity from earlier work, and a likely progression or consolidation opportunity.

This map exists to prevent twelve unrelated workouts. It is not permission to prepopulate all twelve exercise tables. Do not lock in exercises, loads, or progressions before examining preceding classes. Do not force a three-phase or weekly structure unless it is justified for this focus and schedule.

### B. Before developing Class n

Read the saved curriculum brief, provisional map, preceding finalized class, relevant earlier anchor exercises, progression/workload ledger, unresolved issues, and any actual athlete feedback.

Explicitly distinguish:
- **Prescribed work:** what the curriculum documents say should occur.
- **Observed work:** what athletes actually completed and how they responded, only when reported.
- **Unknown response:** information that has not been supplied.

Never claim athletes improved, tolerated a dose, or earned a progression merely because the preceding class was written. Without execution feedback, create a conditional prescription and make its readiness assumptions visible.

### C. Design only the next class in full

1. Write the daily stimulus brief.
2. Define the jobs needed in the 6/2/6 slots.
3. Compare plausible choices for consequential slots and select complementary exercises.
4. Set working doses, loading, recovery, sequence, and quality criteria.
5. Account for total explosive exposure, bilateral/unilateral work, demanding strength work, and likely overlap with other training.
6. Estimate real execution time and delivery requirements.
7. Explain why this class is the appropriate next exposure, not simply a harder or more novel workout.

### D. Audit and revise Class n

Check counts, relevance, duplication, fatigue, technical demands, progression, load selection, recovery, equipment, group delivery, and timing. Revise the class before finalizing it. A polished table is not an audit.

Give particular attention to these questions:
- Does the primary task get sufficient high-quality practice?
- Does every supporting exercise earn its slot?
- Are several exercises loading the same tissues without enough distinct benefit?
- Do the two stabilization exercises leave the athlete ready for primary strength?
- Can all six primary strength exercises be performed productively after the explosive work?
- Are prescriptions clear enough for a coach to run without inventing missing details?

### E. Save, reassess, and hand off

Save the finalized class, then update the ledger and provisional map. Reassess the sequence in light of what was just prescribed and what remains unknown. Record the next class's intended job and conditional progression criteria, **not a prematurely completed next workout**.

At the next run, repeat the review before prescribing Class n+1. By default, stop the present run after this handoff.

## 8. Progression rules

Continuity matters more than novelty. Retain useful anchor exercises long enough for purposeful practice and comparison. An unchanged exercise is acceptable when its role remains useful.

For each recurring anchor, make the following traceable:

**Previous exposure → current prescription → reason for the decision → criterion for the next exposure.**

Possible decisions include maintaining the prescription, adjusting technique or intent, changing load or volume, altering range or execution demands, adding a relevant movement variation, consolidating, or reducing exposure.

Do not automatically increase every variable or make each class harder. Change only the variables justified by the objective and available response data. Regress, hold, or consolidate when appropriate.

Use advance/hold/regress conditions based on observable execution and readiness. Do not fabricate precise percentage targets or pretend different jump variants are directly comparable tests. Keep assessment conditions consistent when comparing an anchor.

Do not assume twelve classes must correspond to twelve consecutive weeks. Recovery and the athlete's full schedule remain separate programming considerations.

## 9. Workload, recovery, and delivery audit

Account for at least:

- Jump, hop, and bound repetitions; distinguish the intensity/type and single-leg versus two-leg demands.
- Throws, sprint repetitions/distances, and other ballistic efforts when applicable.
- Stabilization work and primary working sets, with per-side dosing made explicit.
- Effort targets, rest, equipment changes, and any relevant technical prerequisites.
- Other known sport, gym, and tumbling exposure. Do not insert separate body-control programming.

State counting conventions. Do not count `2 × 6 per leg` as only twelve total repetitions, equate all landing contacts, or label a workload "safe" solely because it fits an arbitrary numerical cap.

Estimate time using actual work, prescribed recovery, preparation sets, transitions, and group/equipment constraints—not a sum of active repetition time alone. Waiting in a rotation may supply recovery only when the actual athlete flow supports it. Do not double-count the same waiting period as separate rest.

If the required work does not fit an established session window, revise dose, equipment flow, or sequence while retaining meaningful work and the exact counts. Do not delete exercises, hide an overrun, or shorten necessary recovery merely to make the timetable appear feasible. Report an unresolved conflict explicitly.

Recovery guidance must be contextual. The example's suggested spacing is not a universal rule for every athlete, curriculum, or sports schedule.

## 10. Required class output

Keep the visible workout practical and close to the reference format below. Use normal Markdown tables with these four columns:

`# | Exercise | Sets × reps | Specific job in this workout`

Distance or duration may replace repetitions where appropriate. Include load/intent, key execution details, and exercise-specific rest in the row or immediately associated notes when the general section notes are insufficient.

Each class must include:

- Title: **[Focus Area] — Class n of 12**.
- Primary effort and foundational athlete assumption.
- A concise quality/performance marker, integrated into a listed exercise rather than added as a fifteenth exercise.
- The four ordered sections with exact 6/2/6 counts.
- Per-exercise dosage and a specific job, not generic "improves athleticism" descriptions.
- Recovery and loading instructions, with preparation sets distinguished from working sets.
- Relevant execution/stop criteria, practical timing, and scheduling notes.
- A short **Progression note**: what was retained/changed and why; what must be demonstrated before the next relevant progression.
- A short **Audit summary** with actual findings, adjustments, and unresolved assumptions.

Keep lengthy comparisons, evidence notes, and workload detail in supporting curriculum files when that makes the coach's class easier to use. Explain conclusions and decision rationales, not private internal deliberation.

## 11. Persistent state and resumption

Follow existing repository conventions when available. Otherwise use:

```text
docs/programming/focus_curricula/<focus_slug>/
  curriculum.md
  progression_ledger.md
  progress.json
  classes/
    class_01.md
    class_02.md
    ...

```

**curriculum.md:** focus mapping, baseline assumptions, equipment/delivery constraints, provisional twelve-class map, relevant evidence/assumptions, and design changes.

**progression_ledger.md:** prescribed exposure totals by class, recurring exercise prescriptions, actual observations only when supplied, rationale for changes, and advance/hold/regress criteria. Keep prescribed and observed data separate.

**progress.json:** track the focus, target class count, last finalized class, next class, finalized file paths, unresolved issues, and exact resume instruction. A finalized document is not evidence that athletes completed that class.

**classes/class_nn.md:** complete coach-ready class with its progression and audit notes. Do not create placeholder class files and count them as finished.

On resumption, verify referenced files actually exist and reconcile inconsistent state before proceeding. Save files only in the current authorized working environment; do not claim writes succeeded without checking. Do not modify unrelated application code, database schemas, deployment settings, or existing exercise records unless explicitly requested.

After each run, provide the new class, saved-file locations, any material limitation, and a one-sentence handoff. Do not announce all twelve classes complete when only the map or a sample exists.

At Class 12, also audit the full sequence for continuity, coverage, realistic progression, and unaddressed assumptions. Correct substantive inconsistencies and document what changed.

## 12. Reference example — Vertical Jumps, Class 1

**Reference status:** The following is the user's supplied format and programming-intent example. It is not a locked exercise list, an independently validated prescription, or an instruction to reuse these exercises in every class. Audit and improve it when warranted while preserving the four sections and exact 6/2/6 structure. A production class must also include the timing, progression, and audit information required above.

# Vertical Jumps — Class 1

**Primary effort:** Improve vertical takeoff through forceful leg extension and coordinated arm action.

**Baseline:** Ages 12–14 with established lifting and landing technique. Loads should follow demonstrated ability, not age alone.

## 1. Access & Prepare 1

Complete your **existing predetermined sequence**.

## 2. Explosiveness — Exactly 6 Exercises

The **standing countermovement jump is the primary performance exercise**. The other five provide supporting practice; keep their volume modest rather than treating all six as full plyometric workouts.

| # | Exercise | Sets × reps | Specific job in this workout |
|---|---|---|---|
| 1 | **Low-amplitude pogo jumps** | 2 × 8 | Practice small, quick ankle-driven rebounds. Stay tall; prioritize rhythm and brief ground contact over height. |
| 2 | **Paused squat jumps** | 2 × 3 | Produce upward takeoff from a stationary position. Hold a comfortable quarter-to-half squat for 2 seconds; jump without dipping again. |
| 3 | **Standing countermovement jump with arm swing** | 3 × 3 | **Main maximum-height practice.** Coordinate the dip, leg drive, and arm swing. Record jump reach. |
| 4 | **Single-leg vertical jump to two-foot landing** | 1 × 3 per leg | Practice upward force production from each leg separately. Use a controlled height and hold the landing for 2 seconds. |
| 5 | **Two-step approach vertical jump** | 2 × 2 | Practice converting a controlled approach into upward movement through a two-foot takeoff. |
| 6 | **Light medicine-ball vertical scoop toss** | 2 × 3 | Practice rapid leg extension against a light external load. Launch upward and slightly forward into a clear throwing area; do not catch the return. |

**Execution:** Reset between individual jumps except pogos. Rest **60 seconds after pogo sets and 90–120 seconds after other sets**, extending recovery when needed. End the exercise when takeoff or landing quality deteriorates—do not chase fatigue.

## 3. Strength (Stabilization/Resilience) — Exactly 2 Exercises

**Light resistance, controlled positions, no grinding or burnout.**

| # | Exercise | Sets × reps | Specific job in this workout |
|---|---|---|---|
| 1 | **Low lateral step-down with a light dumbbell** | 2 × 5 per leg | Practice controlling the pelvis, knee, and foot while accepting weight on one leg. Lower for 3 seconds; lightly touch the free heel down. |
| 2 | **Light-band Pallof press in athletic stance** | 2 × 6 per side | Practice maintaining trunk and pelvic position against a sideways pull. Hold each press for 3 seconds without twisting. |

**Rest:** 30–45 seconds between sets. Finish feeling controlled, not exhausted.

## 4. Strength (Primary) — Exactly 6 Exercises

Use **challenging working loads**, leaving approximately **2–3 technically sound repetitions available**. Perform lighter preparation sets before the loaded compound lifts; the table lists working sets. Qualified supervision and technically controlled loading remain essential.

| # | Exercise | Sets × reps | Specific job in this workout |
|---|---|---|---|
| 1 | **Double-dumbbell front squat** | 3 × 6 | Main bilateral strength exercise: load the squat pattern and drive upward through both legs. |
| 2 | **Dumbbell Romanian deadlift** | 2 × 6 | Load the hip-hinge pattern with controlled lowering and forceful hip extension. |
| 3 | **Dumbbell split squat** | 2 × 6 per leg | Develop each leg's force contribution through a stable split stance. |
| 4 | **Loaded hip thrust** | 2 × 8 | Emphasize strong hip extension through the finish without arching the lower back. |
| 5 | **Loaded standing straight-knee calf raise** | 2 × 8 | Strengthen ankle push-off with the knees nearly straight. Use support so balance does not limit loading. |
| 6 | **Seated dumbbell bent-knee calf raise** | 2 × 10 | Strengthen ankle push-off with the knees bent. Pause at the bottom rather than bouncing. |

**Rest:** 2–3 minutes between compound-lift sets; 60–90 seconds between calf-raise sets. These are strength sets, **not a timed conditioning circuit**.

**Scheduling:** Treat this as a demanding lower-body day. The supplied example proposes approximately **48–72 hours before another comparably demanding lower-body session**, adjusted for recovery and including sport and tumbling loads in the assessment. Validate spacing against the actual athlete schedule rather than applying it mechanically.

## 13. Acceptance checklist

A class is not finalized until these checks have been addressed:

- [ ] Correct requested focus, mapped to the exact seven-category framework.
- [ ] Correct next class number; prior saved work reviewed.
- [ ] Existing Access & Prepare 1 referenced without being created or modified.
- [ ] Exactly six explosive exercise entries, two light-load stabilization/resilience entries, and six primary-strength entries.
- [ ] No hidden extra exercises, filler rows, or unapproved training sections.
- [ ] Clear daily objective, primary performance anchor where appropriate, and specific exercise jobs.
- [ ] Meaningful, differentiated exercise choices with a coherent order.
- [ ] Explicit working doses, loading intent, relevant cues, recovery, and quality criteria.
- [ ] Workload and per-side accounting reviewed; combined explosive and strength demands considered.
- [ ] Exercise equipment and station layout match the confirmed inventory; unconfirmed quantities, capabilities, and space requirements disclosed.
- [ ] Realistic delivery/timing assessed; unknowns and material conflicts disclosed.
- [ ] Progression justified without invented athlete outcomes or automatic escalation.
- [ ] Completed class and state files saved and verified, with a clear next-run instruction.
