**Recovery and quality:** Rest **90 seconds between exercises**, including after E6 before Section 3; extend to 2–3 minutes if control, attention or speed has not returned. Stop the set for pain, jerking, unwanted rotation, hard/asymmetric hand reception or clear loss of speed; reduce load/complexity for remaining work only if control returns. Otherwise stop and record the shortfall. Do not make up missed reps or count a non-flight press as a hand landing.

**Delivery:** Use a protected forward-release bay, inspected self-anchored band setup, stable floor/row supports and light dumbbells. No overhead attachment, moving release or coach feed is required.
