Per-bout work is reps × movement seconds plus (reps − 1) × reset seconds; repeated sets add listed rests and side-specific work adds listed side rests. Preparation movement is budgeted at approximately 3 seconds per rep. Terminal rest is counted as a transition, not added again. Extra rest or setup can extend this estimate. For a group, measure actual turns: a waiting period replaces a required rest only when it is at least as long and actually passive; do not add both as separate rest. With one coach use one active high-attention station at a time and keep other athletes behind the clearance boundary. No group size, staffing adequacy, space or station inventory is assumed.

Coach controls every feed in a protected lane; only a ball manageable by one arm is permitted. Use the same inspection/clearance rules for the bilateral release. Keep the supported-row and floor-press stations outside ball paths; inspect minimum landmine load and the overhead band attachment. No one-arm hanging or unsupported ballistic dumbbell catch is required. Inspect throwing containment, band anchoring, supports and load handling before delivery. No wall/rack/cable machine is inferred from ball/bar ownership. Replacements retain the remaining slot dose and rest unless an explicit replacement dose is stated. Recalculate actual repetitions, laterality, releases, contacts and time when the task changes; an undeliverable slot is not silently counted as completed.
