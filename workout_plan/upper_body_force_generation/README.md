# Upper-body force generation — complete 12-class plan

All 12 conditional coaching prescriptions are written and individually audited for ages 12–14 with established basic lifting technique. The exact seven-category framework is in [curriculum.md](curriculum.md). Every class references existing **Access & Prepare 1**, then prescribes **6 explosive drills, 2 light stabilization/resilience exercises and 6 challenging primary-strength exercises**.

**Start here:** [Full coach manual](UPPER_BODY_12_CLASS_PLAN.md). Each class below can also be used separately.

Unique relevant drills were prioritized; related variants and justified repetitions are identified in the [drill register](drill_usage.md). Recurring strength lifts have [previous → current → reason → next criterion records](strength_progressions.md). No athlete completion, earned progression or improvement is assumed.
