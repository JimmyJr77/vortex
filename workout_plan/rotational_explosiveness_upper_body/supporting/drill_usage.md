# Drill usage — upper-body rotational explosiveness

**User preference, 2026-09-13:** Strongly prioritize unique drills across the twelve classes; strength lifts may recur as needed for progressions. This register tracks **prescriptions**, not proof that athletes performed them. Finalized classes are listed in the current progress state and the chronological records below.

## Before selecting the next class

Read all finalized class files, this register and any actual substitutions/feedback. For each explosive and light resilience candidate, identify its nearest prior task and state the specific relevant difference. Names, sides, loads, doses, target surfaces and cosmetic setup changes do not establish uniqueness. A different implement alone is insufficient. Prefer another meaningful task when a candidate merely reproduces a prior drill's job.

Carry the day's rotational objective and quality criteria forward; new drills should still be directly relevant. Do not increase complexity, intensity or volume just to be different. If no suitable distinct choice meets the task/readiness constraints, record the necessary recurrence and explain the alternatives considered. Primary lifts may recur with an explicit progression purpose; light-strength recurrence requires a purpose too and must remain light.
