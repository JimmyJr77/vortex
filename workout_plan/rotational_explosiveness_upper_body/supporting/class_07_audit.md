## Delivery/time and unresolved requirements

Explosive ~29, light ~4, primary ~37, section/logging ~4 minutes; plan 70–85 minutes plus unknown existing preparation/queues. Model includes attempts, resets, full recovery, the prescribed load-preparation sets, demonstrations and loading. Actual athlete count/coach coverage, minimum implement loads, anchors, ball containment, lane widths, floor/target suitability and preparation remain coach-verification inputs. A qualified feeder must stand beside/behind the athlete outside the release corridor and never become the throw target. The feeder supplies one light ball after the lane is clear, releases hands before the athlete turns, and waits for the outgoing ball to settle. If handoff/feeder positioning cannot be arranged, use the equivalent self-held return instead at the same dose and record it as a regression/recurrence. No blind, hard, overhead incoming or rebound feeds. Baseline: 20 handoffs, zero airborne catches; if all four receiving rows use verified gentle feeds instead: 20 airborne catches, not 20 additional reps. Extend setup/retrieval time for the actual feeder flow.
