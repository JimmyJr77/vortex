## Delivery/time and unresolved requirements

Explosive ~30, light ~5, primary ~41, section/logging ~4 minutes; plan 80–90 minutes plus unknown existing preparation/queues. Model includes attempts, resets, full recovery, the prescribed load-preparation sets, demonstrations and loading. Actual athlete count/coach coverage, minimum implement loads, anchors, ball containment, lane widths, floor/target suitability and preparation remain coach-verification inputs. The arc press requires a securely anchored landmine whose minimum bar load can be moved briskly without shrugging; use an unloaded two-hand transverse shadow sweep instead if that minimum load is unsuitable, same dose and logged. Overhead projection requires overhead clearance and a compatible ball/target; use a two-hand rotational chest push instead if comfortable overhead positioning is unavailable, rather than forcing range. These are replacements, not extra drills.
