# Rotational Explosiveness — upper-body 12-class curriculum

**All 12 class prescriptions are finalized.** Each class uses existing **Access & Prepare 1 → 6 explosive exercises → 2 light stabilization/resilience exercises → 6 challenging primary-strength exercises**. The exact seven-category framework is preserved in [curriculum.md](curriculum.md).

Baseline: ages 12–14 with established basic lifting/landing technique and qualified supervision. These are twelve numbered exposures, not twelve consecutive days. Athlete completion, response and recovery remain unknown.

Read the [combined coach manual](coach_manual.md), [full-sequence audit](supporting/full_sequence_audit.md), [progression/workload ledger](progression_ledger.md), [drill-usage register](supporting/drill_usage.md), [sources/library record](supporting/sources_and_library.md) and [feedback form](athlete_feedback.md).

*Work time includes the listed lifting preparation, demonstrations, recovery and transitions. Add the unknown existing Access & Prepare 1 duration and actual group queues. Complete session bookings remain unconfirmed. A 60-minute total booking is not supported by these prescriptions. Ball releases and other fast actions are different loading types, not equivalent workload points.

**Uniqueness:** Meaningfully distinct drills are prioritized. Related variants are compared by their task demands; deliberate recurrences are labeled for consolidation, load management or reference observations. Strength lifts recur with class-specific progression/hold decisions. There is no claim of 72 unrelated explosive drills.

**Before delivery:** Verify ball/floor or throwing-wall compatibility and containment in the 10 m lanes, band/rope anchors, manageable implement loads/grips, staffing, group timing and actual preparation. Classes 7, 11 and 12 use controlled handoffs by default; only Class 7 offers gentle airborne feeds as a same-dose option after demonstrated receiving readiness. Never infer readiness from a class number.

**Handoff:** The written curriculum is complete. Deliver the next appropriate class only after checking actual readiness and schedule, record real work and recovery, and revise remaining prescriptions as needed. No Class 13 or additional training block has been created.
