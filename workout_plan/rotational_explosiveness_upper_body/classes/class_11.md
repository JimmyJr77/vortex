# Rotational Explosiveness — Upper Body — Class 11 of 12

**Primary effort:** Organize an externally supplied ball into a deliberate entry or constrained-base release without rushing the turn.

**Framework:** Rotational explosiveness > Upper-body emphasis (rotational throws, punches, and swings). Existing seven-category framework in the curriculum remains unchanged. Foundational athletes: ages 12–14 with established basic lifting/landing technique and qualified supervision.

**Daily stimulus brief:** E1 joins a controlled handoff to one short step and a scoop release. The limitation is hurrying the body before grip and base are organized. A constrained-base supplied press and a supplied one-arm low release extend that same problem to different hand contributions. Small familiar band, rope and self-held step-press tasks provide predictable references. Strength consolidates at one set per lift before the final review class.

**Integrated quality marker:** For E1 record secure grip after the feeder fully lets go, a deliberate planted step before the turn, and a balanced release finish. Record input timing and actual step size; do not score a faster handoff as better performance. Observe during the scheduled anchor attempts, count all attempted work, and do not add testing reps. A different drill is not a comparable performance test or evidence of improvement.

**Review before design:** Read the saved curriculum/map, preceding Class 10, workload/progression ledger, drill usage and feedback; source hashes are retained with this class record. Class 10 prescribed twenty releases, twelve other fast actions and 82 primary reps. This class retains twenty releases but lowers other fast actions and primary reps. No actual feedback has established readiness for faster incoming balls, so this class uses handoffs only, with zero prescribed airborne catches. **Prescribed is not observed:** no athlete execution/response has been supplied; this is a conditional prescription.

## 2. Explosiveness

**Exactly six exercises.** E1–E3 receive a controlled handoff only; no airborne feed or surprise signal. E1 gets 2 × 2 per side and all supports 1 × 2. The feeder lets go before any step or turn. One supplied-ball return remains one integrated exercise rep. Use light implements and fast coordinated intent; a retained-load drill ends under control rather than being released. Both sides receive the written dose.

### Delivery, loading and stop rules

**Athlete and readiness:** Ages 12–14 with established basic lifting/landing technique; rotational and implement-specific competence still needs coach observation. Earlier class files are prescribed work only. Actual attendance, technique, loads, soreness and recovery remain unknown. Do not presume the class number grants readiness. On the first scheduled repetitions, use manageable range/resistance and apply the listed regression; these attempts count, not extra tests. Pain, uncontrolled rotation or unsafe equipment/ball paths stop the affected work; record incomplete delivery rather than making up attempts.

**Ball/station setup:** Use the same conditional floor-target approach documented in Class 1: a low forward ball release into a target roughly 2–3 m beyond the release point, compatible low-rebound ball and impact-permitted floor, with the entire flight/rebound/roll contained inside an excluded 10 m lane. Verify width and side clearance. A suitable throwing wall may be used instead only after verification, with no rebound catches unless a row explicitly prescribes receiving. Do not force a heavy ball to shorten flight. For entering drills, all footwork stays within a 1 m start bay and there is no hop, jump or sprint. Three lanes are not one 30 m runway. If neither floor nor approved wall containment works, arrange an approved area and re-audit before delivery.

**Additional setup for this class:** Feeder stands beside/behind the athlete outside the outgoing corridor. Handoff into secure hands, step clear, then let the athlete initiate. No handoff while the athlete is moving. If feeder coverage is unavailable, use the self-held equivalent at the same dose and record recurrence. A grippable ball is required for the one-arm low release; use a two-hand scoop instead if grip size is unsuitable. Sixteen prescribed handoffs are receptions, not airborne catches.

**Recovery/loading:** Ball releases and other fast actions are discrete efforts with 10–15 s between repetitions for controlled reset; no conditioning circuits. Use the row's between-bout recovery (60 s for small supports, 90 s for the anchor/higher-demand work), and at least 60 s between explosive exercises; extend it to preserve speed/control. Left and right are separate bouts. Do not trade away rest to fit a clock. Light strength stays at least 4 clean repetitions in reserve, with 30–45 s between sides and 45–60 s between its two exercises. Primary resistance is challenging at about 2–3 technically sound repetitions in reserve; keep the indicated tempo and choose each side's appropriate load. Rest 90 s between primary side bouts/exercises, 2 min between rounds of a two-set lift and 2–3 min between Landmine Rotation sets. Equipment changes/queues can supply that rest only when elapsed time actually suffices; count time once.

**Load-preparation sets:** Before each listed primary lift, perform one easy set of 3 per side using lighter resistance; for alternating Landmine Rotation use 4 traverses total instead. These are the same six exercises, not additional slots. Allow 30–45 s to change sides and 60–90 s before working. Minimum preparation is **34 easy reps in 11 bouts**, separate from working work. If another preparation set is needed, repeat that lift's easy dose, log it and add the time. No max tests or forced reps. Secure band anchors and landmine; if the minimum bar is unsuitable, use the same-dose standing two-hand band rotation or one-arm rotational band press instead of the relevant landmine lift, recording the proposed replacement.

**Timing and group flow:** About **70–85 minutes for this prescribed work**, excluding existing Access & Prepare 1 and additional group queues. Model: explosive 28 min including resets/bout rest and ~7 min coaching/setup; light strength 5 min; primary strength 37 min including listed preparation, work, recovery and ~7 min loading/instruction; ~4 min section changes/logging. This is an individual/small-wave estimate, not a confirmed booking. One active throwing area at a time; clear it before lifting. **Scheduling:** Review actual throwing/batting/racquet/swinging/contact-sport work, upper-body lifting and separately programmed tumbling before this exposure. ### Workload and progression

**Prescribed workload:** 20 ball releases (20 throws + 0 slams), separately **8 retained-load/unloaded fast actions**, and 16 prescribed ball receptions. Explosive work comprises 14 physical side bouts. These are different loading types, not equivalent contact units. The accompanying record separates side counts and action types.

**Progression decision:** Rotational press decreases from Class 10 two sets to one; all primary lifts use one set, totaling 70 reps. No load increase is presumed. The sixteen handoffs add external organization, but zero incoming flight is prescribed and no entry speed is raised. These are conditional integration tasks rather than proof of progress. Hold self-held alternatives if grip or input timing is not controlled. Class 12 should repeat selected exact references within its six explosive slots only when actual earlier setup data exists; otherwise treat its attempts as first observations, not improvement tests. New tasks do not establish readiness or justify heavier loads. Hold or regress when actual feedback is absent or control/recovery is insufficient. For any recurring lift, retain a controllable load until clean work at the intended reserve and acceptable recovery are actually reported; then change one appropriate variable, not load, range and volume together.
