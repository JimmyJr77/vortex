# Class 2 — sources and exercise identity check

**Reviewed 2026-09-13.** The [original register](sources_and_exercises.md) continues to document the overall biomechanical rationale, youth guidance and retained strength identities. New sources below support limited drill-selection rationale. They do not validate this complete class or show that these athletes improved.

## Additional coaching sources

- [Overtime Athletes — Increase Your Quickness with 3 Acceleration Drills](https://blog.overtimeathletes.com/increase-your-quickness-with-3-acceleration-drills/): wall-supported leg exchanges and start mechanics inspired E2's job. Class 2 uses isolated exchanges, a verified-support condition and a floor fallback; it does not import universal body angles, aggressive clawing cues or outcome promises.
- [Overtime Athletes — Pro Level Plyometrics Training Pt. 1](https://blog.overtimeathletes.com/pro-level-plyometrics-training-pt-1/): supports the stylistic distinction between unilateral power and seated leg-extension tasks. The article's elite sequence, obstacles, repeated bounds, drop-rebound work and competition are not copied into this youth prescription.
- [Catalyst Athletics — Seated Vertical Jump](https://www.catalystathletics.com/exercise/624/Seated-Vertical-Jump/): official exercise guidance for using supported sitting before a jump. The intended reduction in countermovement contribution explains E3; it does not establish a measured sprint benefit or prove all elastic contribution is absent in an actual attempt.
- [OTA's previously reviewed speed-drill article](https://blog.overtimeathletes.com/soccer-speed-drills/) includes a half-kneeling start. The shorter two-step/3 m driving boundary and four-attempt dose are authored for this facility. They are not the article's tested intervention or a full acceleration exposure.

Stationary low dribbling is a constrained coordination adaptation of the locally researched traveling drill. No new research result is claimed for that adaptation. Existing hip/ankle biomechanics sources inform intended capacity roles only; the class requires athlete response and coaching judgment, not an assumed transfer coefficient.

**Replacement record:** High-Plank Single-Switch Knee Drive is a proposed floor-supported rapid-exchange replacement, not a wall drill under a different name. Squat Jump to Stick is a declared unsupported static-origin replacement; no current variant binding is claimed. Low two-point standing start and bilateral Ankle Pogo in Place recur from Class 1's families only when the documented comfort/readiness condition requires them. One-step start reduces drive opportunities within the same attempt; it does not create another slot. Supported single-leg P5, seated short-foot and fitted seat substitutions retain the earlier declared replacement rules.

**Uniqueness conclusion:** All six defaults differ from Class 1 by meaningful starting support, laterality, force direction or cyclic coordination. Their labels alone are not the evidence; the audit and history spell out the changed jobs. Necessary fallback recurrence is disclosed rather than relabeled. Nothing in this review establishes performance improvement across different drills.
