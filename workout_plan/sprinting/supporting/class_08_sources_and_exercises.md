## History and practical qualifications

Default distinctions concern initial support, immediate force reuse, receiving stance, linked exchange, recovery pattern or implement release. A different name, cue or rep count alone receives no novelty credit. The double-switch and running drills remain related families. Every earlier default and contingency was considered; replacements deliberately repeat useful earlier tasks.

If E2 and E3 both need parallel isolated broad-jump replacements, E3 switches instead to the documented same-lead split jump, avoiding duplicate slots. E6's parked-swing and rapid-bridge alternatives are explicit recurrences. Replacements change exposure and comparison conditions and are never added to defaults.

Wall, start footprint, lane width, low-rebound ball behavior, floor rating, overhead clearance and group flow remain unconfirmed. A short target does not prove throw containment; use the non-throwing path when needed. All observed attendance, load, completion and recovery remain unknown. No exercise-library or application records were edited.
