2. **Demand addressed:** organize the transition from lowering to upward propulsion without a second dip, excessive travel or an interrupted arm action. These are possible observations to check, not faults attributed to an unobserved athlete.

## Selection and revision findings

| Question / alternative considered | Final decision and consequence |
|---|---|
| Add a CMJ set or more contacts to make a “progression”? | Keep 3 × 3. There is no actual response evidence to support added exposure. Three sets already allow observing and then practicing a useful cue. |
| Replace an explosive slot with a hands-on-hips CMJ? | Retain the natural-arm anchor and existing paused-start task. A new arm-restricted CMJ could muddy the comparison and displace a distinct job without a demonstrated need. |
| Make unilateral landings or approach speed harder? | Retain bilateral landing after each-leg takeoff and the controlled two-step entry. Neither skill nor tissue tolerance was established by saving Class 1. |
| Rotate strength exercises for variety? | Keep all six, with the squat and RDL receiving the largest investment. Their exact roles remain relevant and recorded prior prescriptions provide continuity, even though actual load history is absent. |
| Increase every lift when the athlete reaches a rep target? | No preset increase. Use any actually recorded compatible load as information, then select for today's 2–3 technical RIR through the specified preparation. A rep count alone does not establish recovered readiness. |
| Does repeated calf/hip work exceed its distinct benefit? | The knee-position difference between calf tasks and hip-range/support difference between RDL and hip thrust still earn the slots. Retain low support volumes: one working hip-thrust set, one split-squat set per leg and one standing calf set per leg. Review actual fatigue before future additions. |
| Could the light work pre-fatigue primary strength? | Keep one step-down round and short supported foot holds, with at least five reps' reserve/comparable ease. Support removes unnecessary balance demand. Neither task becomes a longer hold or burnout set. |
| Can teaching be shorter because this is Class 2? | No. Actual attendance and familiarity are unknown. Preserve Class 1's demonstration/setup allowances. Fit a concise cue into E2's already scheduled rest or add time if required. |

**Concrete instructional revision:** E2 now explicitly uses set 1 for observation, selects at most one cue from an actually seen issue, and records valid attempts per set and fault recurrence in sets 2–3. It keeps the original performance protocol. Missing technique data is not treated as a diagnosis; clean execution does not trigger needless correction. E4 also specifies a default starting-side order when previous actual order is unavailable.

**Programming outcome:** identical written dose is the deliberate decision at this point. Class 2 adds an instructional job while preserving a challenging, focused strength prescription. It does not prove athlete improvement or transform the twelve-class map into automatic overload.
